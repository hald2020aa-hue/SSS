# SSS — Kotatsu Neon Edition

نسخة مخصصة واحترافية مستوحاة من تطبيق **Kotatsu** لقراءة المانجا، مصممة بهوية **SSS** مع 6 خلفيات نيون داكنة، تخصيص شامل لتوزيع العناصر وتنسيق الأيقونات، مزامنة سحابية عبر **Firebase Firestore**، وأدوات متقدمة لتحليل بيانات الاستخدام.

## 🚀 بناء التطبيق عبر GitHub Actions (CI/CD)

تم تجهيز المستودع بملف سير عمل تلقائي في المسار:
`.github/workflows/android-build.yml`

### خطوات تشغيل البناء على GitHub واستخراج ملف الـ APK:
1. من القائمة العلوية في **AI Studio**، اضغط على أيقونة **التصدير إلى GitHub (Push to GitHub)** لرفع الكود إلى مستودعك الخاص.
2. بمجرد رفع الكود إلى الفرع `main`، سيبدأ سير العمل **SSS Android Build (APK & Bundle)** تلقائياً في تبويب **Actions** داخل مستودعك على GitHub.
3. يمكنك أيضاً تشغيل البناء يدوياً في أي وقت بالدخول إلى تبويب **Actions** -> اختيار **SSS Android Build (APK & Bundle)** -> الضغط على **Run workflow** واختيار نوع النسخة (`debug` أو `release` أو `both`).
4. بعد اكتمال البناء (حوالي دقيقتين)، انزل إلى قسم **Artifacts** في صفحة البناء وحمّل ملف **`SSS-Kotatsu-Neon-Debug-APK`** أو **`SSS-Kotatsu-Neon-Release-APK`** لتثبيته مباشرة على هاتفك الأندرويد.

## ✨ المميزات الرئيسية
- **6 ثيمات نيون داكنة**: Cyber Cyan, Neon Magenta, Electric Violet, Matrix Emerald, Solar Amber, Crimson Laser.
- **تخصيص واسع للواجهة**: التحكم في توزيع البطاقات (شبكة ثلاثية، ثنائية، قائمة، متدرجة)، موضع شريط التنقل، وترتيب أقسام الشاشة الرئيسية.
- **4 أنماط لتنسيق الأيقونات**: Neon Glow, Minimal Outline, Solid Cyber, Duotone Ring.
- **مزامنة سحابية فورية**: حفظ ومزامنة الأنماط المخصصة والمكتبة وتقدم الفصول عبر حساب Google.
- **تحليلات الاستخدام الذكية**: رسوم بيانية لسرعة القراءة وتوصيات آلية لتحسين تجربة المستخدم بضغطة واحدة.
